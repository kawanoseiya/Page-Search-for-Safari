# Page Search for Safari 要件定義書

## 1. 概要

### アプリ名

**Page Search for Safari**

### コンセプト

Safariで開いているWebページ内の文字を、すばやく検索するためのSafari拡張。

Safari標準のページ内検索よりも、見つけやすく、操作しやすい検索UIを提供する。

### 一言説明

**Safariのページ内検索を、もっと簡単に。**

---

## 2. 対象プラットフォーム

* iPhone
* iPad
* Mac
* Safari Extension

---

## 3. 対象ユーザー

* 長いWebページから文字を探したい人
* Safari標準のページ内検索が使いにくい人
* マニュアル、ニュース、掲示板、商品ページなどをよく読む人

---

## 4. コア機能

### 4.1 検索キーワード入力

Safari拡張を開くと、検索入力欄を表示する。

ユーザーが文字を入力すると、現在表示中のページから該当文字列を検索する。

### 4.2 検索結果のハイライト

一致した文字列をWebページ上でハイライト表示する。

現在選択中の一致箇所は、他の一致箇所と区別して表示する。

### 4.3 前後移動

以下のボタンを表示する。

* 前の一致箇所
* 次の一致箇所

ボタンを押すと、該当位置まで自動スクロールする。

### 4.4 検索件数表示

検索結果を以下の形式で表示する。

`3 / 12`

左側が現在選択中の番号、右側が総一致件数。

### 4.5 検索終了

閉じるボタンを押すと、検索UIとハイライトを解除する。

---

## 5. 画面構成

### 5.1 Safari拡張画面

表示項目は以下のみとする。

* 検索入力欄
* 前へボタン
* 次へボタン
* 検索件数
* 閉じるボタン

```text

│ 検索キーワード        ×   │
├────────────────────────────┤

```

---

## 6. 操作フロー

1. SafariでWebページを開く
2. Page Search for Safariを起動する
3. 検索キーワードを入力する
4. 一致箇所がページ上でハイライトされる
5. 前後ボタンで一致箇所を移動する
6. 閉じるボタンで検索を終了する

---

## 7. 検索仕様

### 7.1 基本仕様

* 部分一致検索
* 大文字・小文字は区別しない
* 日本語、英語、数字に対応
* 入力中にリアルタイム検索
* 空欄の場合はハイライトを表示しない

### 7.2 対象範囲

現在のWebページ内に表示されているテキストを検索対象とする。

以下は初期バージョンでは対象外とする。

* iframe内部
* PDF
* 画像内の文字
* 動画字幕
* ページ読み込み前の要素
* 閉じられたシャドーDOM
* 折りたたみ内の未生成コンテンツ

---

## 8. 検索結果がない場合

検索結果が0件の場合、件数部分に以下を表示する。

`0件`

前後移動ボタンは無効化する。

---

## 9. 権限

Safari拡張として、現在表示しているWebページの内容を読み取り、ハイライトを追加する権限を使用する。

取得したページ内容や検索キーワードは外部サーバーへ送信しない。

---

## 10. データ保存

初期バージョンでは、検索履歴や検索キーワードを保存しない。

拡張を閉じた時点で検索状態を破棄する。

---

すべて端末内で処理する。

```text

├── PageSearchForSafari.xcodeproj
├── icon-source.svg              アイコンの原本（これを編集する）
├── generate_icons.sh            全サイズのアイコンを再生成
├── PageSearchForSafari/         アプリ本体（有効化ガイドを表示するだけ）
│   ├── ViewController.swift     WKWebViewでガイドを表示・設定アプリを開く
│   └── Resources/
│       ├── Base.lproj/Main.html 英語のガイド
│       ├── ja.lproj/Main.html   日本語のガイド
│       ├── Main.js              「設定を開く」ボタンのブリッジ
│       └── Style.css
└── PageSearchForSafari Extension/
    ├── SafariWebExtensionHandler.swift
    └── Resources/
        ├── manifest.json        Manifest V3
        ├── popup.html/css/js    検索UI（入力欄・前後ボタン・件数・閉じる）
        ├── content.js           テキスト走査・ハイライト・前後移動
        ├── content.css          ハイライトの見た目
        └── _locales/{en,ja}/messages.json
```

### 検索の仕組み

1. `TreeWalker` で `document.body` のテキストノードを収集する。
   `script` / `style` / `textarea` などのタグと、`display:none` などで非表示の要素は除外する。
2. 収集したテキストを1本の文字列に連結し、各ノードの開始位置を記録する。
3. 文字列長を変えない小文字化を行い、`indexOf` で全一致箇所を求める。
4. 一致箇所を**後ろから順に** `<mark>` で囲む。前から囲むとテキストノードが分割され、
   以降の位置がずれるため。
5. 要素をまたぐ一致（例: `Wor<b>ld</b>`）は複数の `<mark>` になるが、1件として数える。
6. 解除時は `<mark>` を外し、親ノードを `normalize()` して元のDOMに戻す。

上限は2000件。極端に一般的な語でタブが固まるのを防ぐ。

### ビルド

```bash
cd PageSearchForSafari
xcodebuild -project PageSearchForSafari.xcodeproj -scheme PageSearchForSafari \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

アイコンを変えるときは `icon-source.svg` を編集して `./generate_icons.sh` を実行する。
